# Security policy

The 1.x release line is the initial supported line. Review the latest
available release before reporting a problem.

For a vulnerability in AI Code Guardian, use **Security → Report a
vulnerability** on its GitHub repository when private vulnerability reporting
is enabled. If the option is unavailable, open an issue asking for a private
way to contact the maintainer. Keep technical details out of that issue.

In a private report, include the CLI and Python versions, operating system,
affected command, impact, and a minimal example with fabricated data. Remove
credentials, private source, package names that are confidential, and sensitive
paths before sharing logs or reports. If a real credential was exposed, rotate
or revoke it with its provider.

See the [README](README.md#privacy-and-limitations) for what each scan reads
and what the optional audit sends to PyPI.
